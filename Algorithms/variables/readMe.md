# Variables

In this activity you will be declaring and using JavaScript variables with `var`, `let`, and `const`.

## Instructions

1. Open `variables.js` in your code editor—this is the only file you will modify in this activity.

2. In `variables.js`, you will see example comments showing how to declare:
   - **`var`** → function-scoped, can be redeclared & updated  
   - **`let`** → block-scoped, can be updated but NOT redeclared in the same scope  
   - **`const`** → block-scoped, cannot be reassigned (though objects/arrays can be mutated)

3. Write code to declare and assign these five variables:
   1. `myVar` (string `"apple"`, use `var`)  
   2. `myNum` (number `5`, use `let`)  
   3. `myBool` (boolean `true`, use `const`)  
   4. `myArr` (array `["apple", 5, true]`, use `const`)  
   5. `myObj` (object `{ name: "Alice", age: 30 }`, use `let`)

4. Save your changes.

5. Open `test.html` in your web browser:
   - Passing tests are marked with a green check.  
   - Failing tests are marked with a red X and an error message.

## Hints

- End each statement with a semicolon.  
- Typos in variable names or keywords (`var`, `let`, `const`) will cause tests to fail.
